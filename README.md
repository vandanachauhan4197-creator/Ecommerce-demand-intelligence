# E-commerce Demand Intelligence & Inventory Optimization Platform

An end-to-end Data Science project focused on retail demand forecasting, time-series analysis, revenue prediction and inventory optimization.

## Project Objectives

- Analyse historical retail sales data.
- Identify trends, seasonality and demand patterns.
- Perform statistical time-series analysis.
- Forecast product demand for 30, 60 and 90 days.
- Compare statistical and machine learning forecasting models.
- Develop inventory and replenishment recommendations.
- Build an interactive business intelligence dashboard.

## Technology Stack

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Statsmodels
- ARIMA / SARIMA
- Prophet
- XGBoost
- SQL
- Power BI
- Streamlit

## Project Structure

- `data/` — Raw, processed and external datasets.
- `notebooks/` — Exploratory analysis and modelling.
- `src/` — Reusable Python modules.
- `sql/` — Database schema and analytical queries.
- `dashboard/` — Interactive dashboard.
- `models/` — Trained forecasting models.
- `reports/` — Analysis and evaluation reports.
- `tests/` — Project tests.

## Data Sources

Primary dataset: Walmart M5 Forecasting.

External data: Public economic indicators through the FRED API.

Inventory data: Documented simulation based on configurable inventory assumptions.
